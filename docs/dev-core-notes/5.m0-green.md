# 5 - M0 GREEN: shielded receipt wrapped to Groth16

The gate is closed. The Experiment-2 shielded, commitment-bound proof was wrapped
to Groth16 on x86 and produced a 256-byte seal - the proof the Solana verifier
checks (<200k CU). Half B is no longer "feasible, assessed from source"; it is
**demonstrated**.

## What this actually proves (the load-bearing point)

The receipt from `execute_and_prove` carries the predicate program composed as a
**resolved assumption** (that's how the privacy circuit composes the program
proof). Wrapping a receipt-with-resolved-assumptions to Groth16 was the ONE
unconfirmed step in the whole architecture - the litepaper's Half B caveat #3,
"standard but worth an empirical confirmation."

It compressed cleanly. No special handling, no assumption-resolution wrinkle. So
the full shielded path - confidential execution on Logos → succinct receipt →
Groth16 → Solana-verifiable seal - is proven end to end, on real proofs.

## Environment / cost notes

- DigitalOcean `s-4vcpu-8gb` (8 GB, x86), Ubuntu 24.04, Bangalore.
- Deps on the box: Rust + Docker ONLY. No rzup / guest toolchain needed - the
  prover wraps an existing receipt, it builds no guest.
- Added 8 GB swap before the run (8 GB RAM alone is tight for stark2snark).
- **Cold build was ~63 min** (risc0 C++ circuit sources from scratch, no cache).
  One-time per fresh box. The wrap itself was fast. For repeat runs, keep a
  snapshot or a persistent build cache to skip the 63 min.
- Docker pulls the RISC Zero Groth16 prover image on first compress.
