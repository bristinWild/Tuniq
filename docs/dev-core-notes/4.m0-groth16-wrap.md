# 4 — M0: the Groth16 wrap on x86 (the gate)

Wrapping the captured succinct receipt to Groth16. This is the one step that
needs x86 + Docker (the stark2snark compression), so it runs on a short-lived
DigitalOcean droplet. The droplet needs only Rust + Docker — NOT the RISC Zero
guest toolchain, because the prover wraps an existing receipt; it builds no guest.

Inputs (from `predicate-engine/artifacts/`): proof.bin, journal.bin, image_id.txt
Output: seal.bin (256-byte Groth16 seal)

---

## 1. Create the droplet

DigitalOcean console → Create → Droplet:
- Image: **Ubuntu 24.04 LTS**
- Type: **Basic → Regular**, **8 GB RAM / 4 vCPU** (groth16 + Docker need headroom;
  16 GB is safer if available)
- Region: nearest (Bangalore / BLR)
- Auth: add your **SSH key** (makes rsync/scp painless)
- Architecture: any standard DO droplet is x86 (Intel/AMD) — no ARM trap here

~$0.07/hr. Destroy it when done; the whole job is well under an hour.

```bash
# from your Mac, save the IP for convenience
export DROPLET=root@<DROPLET_IP>
ssh $DROPLET
```

## 2. System deps + Docker (on the droplet)

```bash
sudo apt-get update
sudo apt-get install -y build-essential pkg-config libssl-dev curl git docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER
newgrp docker            # activate the docker group in this shell (no re-login)
docker run --rm hello-world   # sanity: must succeed WITHOUT sudo
```

If `hello-world` needs sudo, the group isn't active — log out and back in, then retry.

## 3. Rust (on the droplet)

```bash
curl https://sh.rustup.rs -sSf | sh -s -- -y
. "$HOME/.cargo/env"
rustc --version
```

(No `rzup` / RISC Zero toolchain needed — there is no guest to compile.)

## 4. Ship the prover + artifacts (from your Mac)

`rsync` excludes the Mac-built `target/` (it's ARM, useless on x86):

```bash
# from your Mac
rsync -av --exclude target ~/tuniq/prover/ $DROPLET:~/prover/
rsync -av ~/tuniq/predicate-engine/artifacts/ $DROPLET:~/prover/artifacts/
```

The prover reads `artifacts/` relative to its working dir, so they live inside
`~/prover/artifacts/` and you run from `~/prover`.

## 5. Run the wrap (on the droplet)

```bash
cd ~/prover
cargo run --release
```

First run: ~3–4 min to compile, then the stark2snark step pulls the RISC Zero
Groth16 Docker image (a few hundred MB, once) and compresses. Expect a few
minutes total.

Success:

```
Loaded: proof.bin 223835 bytes, journal.bin 696 bytes
Succinct receipt verifies against image id — compressing to Groth16...
WRAP OK — wrote artifacts/seal.bin (256 bytes).
```

That `WRAP OK` is **M0 green** — the moat proof, compressed to a Solana-verifiable
Groth16 seal.

## 6. Retrieve the seal + destroy

```bash
# from your Mac
rsync -av $DROPLET:~/prover/artifacts/seal.bin ~/tuniq/predicate-engine/artifacts/
```

Then destroy the droplet in the DO console (or `doctl compute droplet delete`).

## Troubleshooting

- **OOM during stark2snark** — add swap before running:
  ```bash
  sudo fallocate -l 8G /swapfile && sudo chmod 600 /swapfile
  sudo mkswap /swapfile && sudo swapon /swapfile
  ```
- **Docker permission denied** — `newgrp docker` didn't take; log out/in.
- **`compress` errors on the composed assumption** — this is the genuinely-new
  empirical step. This receipt carries the predicate composed as a *resolved
  assumption* (how `execute_and_prove` works), unlike the standalone receipt
  Exp 3 wrapped. If stark2snark balks here, it is NOT a bug in the prover — it is
  the exact unknown M0 exists to surface, and becomes a precise question for the
  Logos team. The succinct receipt already verified locally (pre-flight), so the
  input is sound.
